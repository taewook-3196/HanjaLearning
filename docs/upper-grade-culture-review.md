| 5급 | 友愛 | 우애를 실천한 모습은? | 친구가 어려울 때 서로 돕고 배려한다 | 실수를 놀린다 / 약속을 일부러 어긴다 / 친구를 속인다 | 友·愛 배정 범위 |

검토 기준:
1. 해당 급수에서 배정 한자를 모두 학습할 수 있는지 확인한다.
2. 정답은 하나이며 오답은 명백한 오류나 지나치게 쉬운 상식만으로 구성되지 않도록 개선한다.
3. 동일·유사 문제 및 표현을 기존 공개 문항과 대조한다.
4. 검토 통과 후에도 우선 DRAFT로 등록하고, 공개 전 별도 검증한다.
5. 3회 연속 50문항 생성 테스트를 통과해야 출제 가능으로 판정한다.
