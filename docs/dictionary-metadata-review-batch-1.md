# 자전 찾기 메타데이터 1차 검수 후보 (미게시)

운영 DB를 읽기 전용으로 조회해 6급·준5급의 자전 찾기 문항 생성 가능 수가 0임을 확인했습니다. 아래 값은 **검수 후보**이며 공식 자전/획수 기준 대조 전에는 DB에 입력하거나 시험에 게시하지 않습니다.

| 한자 | 부수 후보 | 총획수 후보 | 검수 상태 |
|---|---|---:|---|
| 一 | 一 | 1 | 출처 대조 필요 |
| 二 | 二 | 2 | 출처 대조 필요 |
| 三 | 一 | 3 | 출처 대조 필요 |
| 十 | 十 | 2 | 출처 대조 필요 |
| 口 | 口 | 3 | 출처 대조 필요 |
| 土 | 土 | 3 | 출처 대조 필요 |

## 게시 전 필수 확인
1. 대한검정회 적용 자전 기준 및 권위 있는 한자 사전에서 부수·총획수를 각 글자별 교차 확인합니다.
2. 기존 `hanja_exam_metadata` 레코드와 충돌 여부를 검사합니다. 기존 `formation_type` 등 다른 필드는 보존해야 합니다.
3. `source_note`에 확인한 출처와 검수일을 기록하고, 검수 완료 자료만 `PUBLISHED`로 게시합니다.
4. 실제 6급·준5급 전체 출제 풀에서 오답 3개와 정답 1개가 서로 다른지 확인합니다.
5. 사용자 진도·계정·기존 학습 기록은 변경하지 않습니다.

현재 후보만으로 문제 수·난이도가 충분하다고 단정할 수 없습니다. 이 문서는 DB 마이그레이션이 아니며 실제 출제 부족 현상은 아직 해결되지 않았습니다.
