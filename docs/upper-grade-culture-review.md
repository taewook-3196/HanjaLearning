# 상위 급수 문화·예절 문제 검토 후보

상태: **검토 대기**. 운영 DB 미반영. 대한검정회 공식 기출문항을 복제하지 않은 자체 작성 예시다. 급수별 배정 한자 및 난이도 검증 전에는 공개하지 않는다.

| 급수 | 주제 | 문제 | 정답 | 오답 후보 | 검토 사항 |
|---|---|---|---|---|---|
| 5급 | 勤勉 | 근면의 의미와 가장 가까운 행동은? | 맡은 일을 꾸준하고 성실하게 해낸다 | 일을 남에게 미룬다 / 결과만 좋으면 과정을 속인다 / 시작 전에 포기한다 | 勤·勉 배정 범위 |
| 5급 | 友愛 | 우애를 실천한 모습은? | 친구가 어려울 때 서로 돕고 배려한다 | 실수를 놀린다 / 약속을 일부러 어긴다 / 친구를 속인다 | 友·愛 배정 범위 |
| 5급 | 恭遜 | 공손한 태도는? | 상대를 존중하며 예의 바르게 말한다 | 말을 끊는다 / 남을 낮춘다 / 인사를 무시한다 | 恭·遜 배정 범위 |
| 4급 | 信義 | 신의를 지키는 행동은? | 믿음을 저버리지 않고 약속을 지킨다 | 약속을 숨긴다 / 잘못을 떠넘긴다 / 소문을 퍼뜨린다 | 信·義 배정 범위 |
| 4급 | 歲時風俗 | 세시풍속에 대한 설명은? | 절기나 명절에 따라 전해 오는 생활 풍습 | 개인 습관 / 사전 검색 순서 / 시험 방법 | 구성 한자 급수 및 정답의 명확성 |
| 준3급 | 謙讓 | 겸양을 실천하는 태도는? | 겸손하게 다른 사람을 배려하고 양보한다 | 성과 과장 / 의견 강요 / 타인의 실수 악용 | 謙·讓 배정 범위 |
| 준3급 | 冠禮 | 관례에 대한 설명은? | 전통 사회에서 성년이 되었음을 알리는 의례 | 차례 / 마을 놀이 / 신혼여행 | 冠·禮 배정 범위 |
| 3급 | 修身齊家 | 수신제가의 뜻은? | 자신을 수양하고 가정을 바르게 한다 | 남을 속인다 / 재산만 늘린다 / 명예만 우선한다 | 구성 한자 및 선택지 난이도 |
| 3급 | 鄕約 | 향약의 취지는? | 마을 사람들이 서로 선행을 권하고 돕는 자치 규약 | 무역 조약 / 재산 목록 / 과거 시험 문제 | 鄕·約 배정 범위 |

검토 기준:
1. 해당 급수에서 배정 한자를 모두 학습할 수 있는지 확인한다.
2. 정답은 하나이며 오답은 명백한 오류나 지나치게 쉬운 상식만으로 구성되지 않도록 개선한다.
3. 동일·유사 문제 및 표현을 기존 공개 문항과 대조한다.
4. 검토 통과 후에도 우선 DRAFT로 등록하고, 공개 전 별도 검증한다.
5. 3회 연속 50문항 생성 테스트를 통과해야 출제 가능으로 판정한다.
