# 숙달 판정 시간 간격 개선 검토 (2026-10-09)

## 현재 구현 확인
- `record_study_result`의 FLASHCARD KNOWN은 숙달 점수 +8, 복습 단계 +1(최대 7)로 처리한다.
- UNKNOWN은 숙달 점수 -12, 복습 단계 초기화 또는 2단계 감소로 처리한다.
- QUIZ CORRECT/WRONG은 점수 +5/-8, 복습 단계 유지다.
- `sync_hanja_learning_state_trigger`는 점수 >=80, 복습 단계 >=4, 연속 정답 >=3, 연속 오답 0이면 MASTERED로 설정한다.
- 현재 단계 승급에는 `next_review_at` 또는 이전 복습 날짜에 대한 검증이 없다.
- 오늘학습 확인 문제도 `record_study_result`의 QUIZ 경로를 사용한다.

## 위험 시나리오 (운영 데이터 변경 없이 재현 가능)
신규 한자를 같은 날 KNOWN으로 10회 기록하면 점수는 80, 단계는 7, 연속 정답은 10이 되어 MASTERED 조건을 충족한다. 시간 간격 없이 장기 숙달로 판정될 수 있다.

## 권장 설계 — 구현 전 확인 필요
1. 기존 학습 데이터와 점수는 보존한다. 자동 재산정이나 일괄 하향은 하지 않는다.
2. KNOWN을 눌렀을 때 기존 다음 복습 시점이 도래했는지 확인한다. 미도래 시 학습 이력은 남기되 복습 단계 승급을 제한한다.
3. 단순 시간 조건만으로는 기존 사용자에게 과도한 변경이 생길 수 있으므로, 첫 학습과 재학습, 연속 오답 후 회복을 별도 테스트한다.
4. 반복 KNOWN을 통한 점수 누적으로 MASTERED가 되지 않도록 숙달 판정도 '기한을 지킨 복습 성공' 근거를 요구하는지 검토한다.
5. QUIZ 정답·오답과 쓰기 기록, 목표 급수 변경은 기존 동작을 유지한다.
6. 운영 DB의 실제 함수 정의가 저장소의 SQL과 일치하는지 배포 전에 확인한다. 이번 단계에서는 운영 DB를 변경하지 않는다.

## 필수 회귀 테스트
- 첫 KNOWN: 신규 학습이 정상 기록되고 단계 1로 이동
- 같은 날 KNOWN 반복: 이력은 저장되지만 단계가 추가 상승하지 않음
- 다음 복습 시점 이후 KNOWN: 단계가 한 번 상승
- UNKNOWN: 점수 하락 및 재학습 일정 조정
- QUIZ CORRECT/WRONG: 단계 유지, 점수와 연속 정답/오답 갱신
- 동일일 반복으로 MASTERED 도달 불가
- 기존 MASTERED 데이터 및 타 사용자 데이터 보존
- 시간대 경계(KST), 동시 요청, 인증·RLS 및 사용자별 격리
