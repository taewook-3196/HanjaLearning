7급 추가: original-mountain.svg(山), original-mouth.svg(口), original-hand.svg(手).

- SVG는 코드로 새로 그린 단순 도형이며 외부 기출 이미지·삽화 복제물이 아닙니다.
- 그림의 의미가 정답 한자와 충분히 대응하는지 사람의 교육 콘텐츠 검수가 필요합니다. 특히 門·土·口·手는 실제 앱 화면에서 확인하세요.
- 동일 글자 日의 서로 다른 그림은 서로 다른 문항 ID를 갖지만 정답이 같으므로 3회 로테이션의 학습 다양성은 별도 평가해야 합니다.
- 이 PR은 정적 에셋만 추가합니다. 운영 DB hanja_image_items에는 등록하지 않으며 사용자에게 노출되지 않습니다.
- DB 게시 전에 대상 급수, 고유 ID, 정답 연결, 4지선다, 이미지 경로, 접근성 alt, 공개 라이선스를 검증해야 합니다.

## 1차 정적 검수 결과 (2026-10-10)

- **보류: original-earth.svg** — 현재 선과 산 모양이 흙더미보다 산맥/지형으로 읽힐 수 있어 정답 土의 명확성이 부족합니다.
- **보류: original-gate.svg** — 대문의 윤곽은 있으나 중앙 세로선과 대칭 구조가 門 자체의 자형 힌트가 되어 그림의 의미를 묻는 문제인지 자형 맞히기인지 혼재합니다.
- **보류: original-mouth.svg** — 곡선이 웃는 입인지 구분할 수 있지만 얼굴 맥락이 없어 다른 곡선 형태로 읽힐 수 있습니다.
- **보류: original-hand.svg** — 손가락 윤곽이 겹쳐 작은 모바일 화면에서 식별이 어려울 수 있습니다.
- **보류: original-mother.svg** — original-sun.svg와 정답 日 중복으로 연속 회차 다양성이 부족합니다.
- **조건부 후보: original-sun.svg, original-moon.svg, original-tree.svg, original-fire.svg, original-water.svg, original-person.svg, original-mountain.svg** — 정적 SVG 경로와 도형 의미는 검토했으나 실제 기기 렌더링·아동 사용성 검수는 아직 수행하지 않았습니다.

**결론:** 12개 모두 운영 게시 금지 유지. 의미가 불명확한 4개는 도안 수정, 日 중복 1개는 다른 8급 한자로 교체한 뒤 이미지 표시/정답/오답 난이도를 검증해야 합니다.

- original-gate.svg: 아치형 대문 형태로 수정하여 門 자형 직접 모사를 줄임.

이 수정은 SVG 경로의 정적 검토만 수행했습니다. 실제 기기 렌더링 및 아동 검수는 미완료이며, DB에 등록하지 않습니다.

## 그림 문제 오답 난이도 점검 (2026-10-11)

현재 `src/lib/exam-generator.ts`의 `imageQs`는 해당 급수의 한자 목록에서 정답을 제외하고 오답 3개를 무작위 선택합니다. 따라서 네 보기가 서로 다르다는 조건은 충족할 수 있지만, 실제 시험에서 형태나 뜻이 유사한 오답을 우선하는 교육적 난이도는 보장하지 않습니다.

- 日: 月, 目처럼 모양·의미가 가까운 보기 우선 검토
- 木: 本, 禾처럼 모양이 비슷한 보기 우선 검토 (해당 급수에 실제 포함된 한자만 사용)
- 土: 士와 혼동 가능성 검토 (해당 급수에 실제 포함된 경우만)
- 口: 囗, 回 등 형태 혼동 검토 (해당 급수에 실제 포함된 경우만)
- 門: 問, 間 등 자형 유사 한자 검토 (해당 급수에 실제 포함된 경우만)

**검수 원칙:** 대상 급수에 없는 글자를 오답에 끼워 넣지 말고, 현재 급수의 사용 가능한 글자에서 유사도 높은 후보를 우선하되 4개 고유 선택지를 유지합니다. 후보가 부족하면 다른 유효한 글자로 보충합니다. 실제 아이가 그림만 보고 정답을 고를 수 있는지, 작은 화면에서 선이 뭉개지지 않는지는 별도 실기 검수 대상입니다.

**배포 판정:** 정적 CI 검사는 시각적 품질을 보증하지 않으므로 12개 모두 운영 게시 보류. DB 등록·시험 노출 없음.


## 3차 코드·자동화 검증 (2026-10-11)

- PR #461이 `main`에 병합되어 그림 문제도 급수 내 유사 자형 우선 오답 선택을 사용합니다. 단, 정답이 쉽게 드러나는지는 별도의 사람 검수가 필요합니다.
- PR #462가 `main`에 병합되어 그림 문제 생성 100회 회귀 검사가 `test:exam`에 추가되었습니다. 테스트는 합성 한자 풀과 샘플 이미지 메타데이터를 사용하므로 **실제 12개 SVG의 모바일 표시나 실제 급수 데이터 등록을 검증한 것은 아닙니다**.
- 이 브랜치의 SVG 5개(흙, 대문, 입, 손, 어머니와 아이)를 소스 수준에서 다시 확인했습니다. 240×240 viewBox, 배경과 진한 선, 한국어 aria-label이 존재합니다. 이는 렌더링 검수의 대체가 아닙니다.

### 실제 기기에서 통과해야 할 체크리스트

1. 아이폰 Safari와 안드로이드 Chrome에서 각 그림을 작은 시험 보기 크기로 표시하고, 선이 뭉개지거나 잘리지 않는지 확인합니다.
2. 그림만 보고 답을 고르는 아동 검수에서 힌트 없이 뜻을 알아볼 수 있는지 확인합니다. 특히 土(흙더미)와 山(산), 門(대문), 口(입술), 手(손가락), 母(어머니와 아이)를 집중 확인합니다.
3. 실제 급수별 한자 목록과 각 SVG의 `hanja_id`를 대조하고, 8급 9개·7급 3개의 로테이션 수량과 정답 중복 여부를 검증합니다.
4. 등록 후보 12개 각각에 대해 alt 설명, 출처/라이선스, DB 고유 ID, 이미지 경로, 문제 유형, 4개 고유 보기와 정답 매핑을 확인합니다.
5. 위 항목 중 하나라도 미확인 또는 실패면 운영 DB 등록을 보류합니다.

**현재 판정: 검수 보류.** CI 통과는 자동화 검증에 한정됩니다. 실제 기기·아동 검수 및 운영 데이터 연결 확인 전에는 병합 후에도 공개하지 않습니다.
